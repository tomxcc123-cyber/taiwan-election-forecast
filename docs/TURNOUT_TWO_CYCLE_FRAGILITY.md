# 中選會2014—2022投票率雙周期實證：縣市群集不確定性

日期：2026-10-28。用途：網站「投票率」獨立研究頁面的可重現資料品質與穩健性檢驗，**不得直接修正2026正式選舉勝選機率**。

## 已核對資料與歷史周期

2014年地方首長投票所 elprof.csv 的 electoral area（例如臺北市記錄中的「01」）與當屆官方 elbase.csv 行政區名稱（「00」）不同。將2014記錄按縣市＋鄉鎮代碼映射回**當屆中選會原始 elbase 名稱**，並逐站比對有效票、無效票、投票數、選舉人數與已審核縣市總票數，才能恢復對應，不能從2018/2022地圖反填2014。

已核驗資料：2014→2018為22縣市、366個同碼同名鄉鎮市區；2018→2022為21縣市、366個行政區，2022嘉義市未以不相容的資料填補。**同碼同名僅為初篩，不證明村里界或選民構成完全不變**。同名投開票所站號不能視作跨年同一站點。

## 固定公式的原始留出 MAE

| 2018／2022預測方法 | 2018鄉鎮MAE (pp) | 2022鄉鎮MAE (pp) |
|---|---:|---:|
| 上屆鄉鎮率直接延用 | 3.49790 | 6.22726 |
| 前屆偏離縣市均值保留75% | 3.43434 | 6.19825 |
| 前屆偏離縣市均值保留50% | 3.51639 | 6.22147 |

固定75%方案在兩屆上的加權 MAE 分別下降0.06356pp、0.02901pp，幅度很小，不應以「跨兩周期均改善」聲稱有大幅預測增益。MAE 權重僅為各年選後**實際選舉人數**，沒有作為選前模型特徵。

## 新增穩健性評估

對每一個周期、每一個非基準公式，保存：
- 每個縣市的相對基準加權 MAE 差額（正數代表更差）；
- 用完整縣市作抽樣單位，固定種子進行1000次同周期、配對、縣市群集bootstrap；
- bootstrap 的5%到95%分位數（90%經驗區間）；
- 依次刪除一個縣市後重算MAE差額，以及刪除一縣市仍然改善的比例；
- 多少縣市改善、多少縣市惡化。

這些區間只呈現**一個已觀察年份中的地理樣本敏感度**。由於2018與2022不是可交換的獨立同分布選舉，且部分行政區跨屆出現於兩個留出樣本中，不能將這兩個區間解釋為2026年或其後選舉誤差的可信區間，更不能給出投票率對候選人得票變化的因果意義。

## 模型限制

另一個在2022後驗影子模型中表現相對較好的方案——「2014至2018全台率變化保留25%」——沒有在2018預測時可用且相容的2010→2014全台訓練周期，因此**不得在2014→2018測試中偷用2014→2018實際變化作特徵**。本研究只比較嚴格可於該年之前取得的固定收縮係數（100%／75%／50%）；不把同年得票和投票率關聯當選前可用參數。
