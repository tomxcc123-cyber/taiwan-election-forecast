## 模型解讀

新竹市高虹安的登記黨籍為無黨籍，但有國民黨公開支持；嘉義縣吳品叡亦有國民黨支持。原模型的「具名政黨」特徵不能充分表達此類關係。此版新增可追溯的模型缺項標註，**尚未修復或重新估計這個基本面效應**，也沒有為使某人領先而手動改係數。

全台席次仍由完整22縣市抽樣彙總，包含這些尚有缺項的基準結果。頁面明示此限制。正式黨籍、跨黨支持與席次分類是不同概念，無黨籍不自動合併成藍白聯盟。

六個預設為：選定人選+2百分點、−2百分點、−5百分點；來源票流10%、30%；第三名以後向第二名移轉15%。這些只是示例敏感度參數，非歷史訓練的事件衝擊。票流按來源人選當次支持比例計算，不直接把10%當成10百分點。預設不表示退選、人口動員或政黨背書必然帶來某種變化。

## 存檔與自動更新

- `model/evidence.py`建立資料等級和公開證據，不改模擬得票或候選人黨籍。
- `scripts/archive_forecast.py`保存真實建置的精簡基準。初始資料保留修改前已存在的本機建置，不冒充當時已發布的每日預測。
- `data/forecast-history.json`保留每個台北日期、每個產品版本的最後一次摘要，最多180筆。較早同日建置仍可能存在Git歷史，但不出現在頁面摘要清單。
- GitHub Actions沿用每6小時抓取民調，通過建置與檢查後保存摘要；下一次建置讀入存檔。無新民調也可能因時間外推出現差值，不稱為新增民意觀測。
- 「上一組納入民調」按入模題目ID集合比對；不是任意新抓報告或所有修改內容的檢測。
- 版本差值與變動輸入清單不是因素貢獻分解。尚未作固定條件重跑及交互作用處理，不提供偽造的加總歸因。
- 摘要不含歷史完整抽樣，不能單獨重跑過去情境。完整重現需下載當次完整模型快照。
- 公開倉庫中的存檔與Git歷史不會因網站暫停發布而撤回；既有靜態站發布限制仍適用。

## 驗證

75項Python測試通過，涵蓋來源、日期、資料與模型隔離、報告／題目統計、機構去重、快照日界線及原有模型回測。

三組JavaScript引擎測試通過：舊模型、候選人模型、六種新情境；檢驗得票與席次守恆、固定抽樣重現、無效參數拒絕、缺日期空狀態。

Playwright覆蓋七個主站頁、390／768／1440寬度、預設確認及取消、滑块、條件勝選、URL還原、下載、民調故障回復及舊研究頁相容性。通過程式測試不等於統計模型準確率提升。
