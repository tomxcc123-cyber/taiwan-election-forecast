# 官方票數重訓與網站更新

版本：`2026.09-cec-joint.1`。日期：2026-09-08。研究預測，尚未校準。

## 新資料實際用途

| 年份 | 縣市選舉 | 候選人結果 | 用途 |
| --- | ---: | ---: | --- |
| 2014 | 22 | 84 | 初始前屆個人／政黨特徵 |
| 2018 | 22 | 93 | 留出驗證的訓練標籤、2022前屆特徵 |
| 2022 | 22 | 94 | 2022留出測試；完成驗證後用於2026最終重訓 |

7份中選會票數包含補傳的2018六都資料，合計66場、271筆候選人紀錄，不是271個獨立選舉。2026最終模型以44場、187筆候選人結果重新估計ridge係數、尺度及地理交叉擬合残差；保持原有正則化與誤差假設，未用2022成績挑選超參數。2,000次聯合抽樣同步更新81名登記人選、地圖、席次與情境模擬。

以各候選人整数票數除以有效票數，不再使用截短名單、單位小數百分比作新版訓練資料。逐投開票所核對候選人票數合計、有效／無效票與投票數，再核對行政區小計，避免重複累加。嘉義市2022使用12月18日重行選舉，表內縣市總計與東西區總計交叉核對。

舊字體私用字元共4處已依中選會登記／選舉資料核對；原字串及核對連結均保留於各人選的`name_repair`。2018台北168個投票所存在發出票＋用餘票與選舉人數差額，淨差−95；保留原值及逐筆紀錄，不猜測原因、不修改票數，庫存差額不進入預測特徵。

`counts_verified`僅表示上傳表內核對通過。未逐檔比對線上原始檔雜湊，所以`source_verified`、`roster_verified`仍為false；不杜撰歷史公開時間。原始表及壓縮包SHA256、工作表名和讀取行索引隨彙整JSON保留。政黨按原表記錄，無黨籍不按外部支持關係改填KMT、DPP或TPP。

2018年22縣市訓練、2022年22縣市／94候選人結果測試。每場等權重，不將人口大市或多人參選選區當作更多獨立選舉。

基本面90%區間覆蓋率88.03%，平均區間寬51.18百分點；多分類Brier 0.5053、log loss 0.9500。使用固定種子和2,000次抽樣；勝率分數作有限抽樣平滑，不把抽樣中0次當作真實機率為零。

**MAE尚未優於簡單延續基準，不能宣稱全面提升準確率。** 這是已知歷史名單的回溯驗證，非選前180／90／30／7天即時回測。只有1個留出週期；新的資料完整度不是校準證據。動態民調、機構偏差和各項過程誤差仍缺歷史選前快照驗證。現有2題可配對民調不是此次新增的歷史民調。

## 三份TEDS包的處理

- E10137：TEDS2014三都市，包含選後独立樣本、複訪與接觸封面。
- D00196：TEDS2018面訪，實際訪問2019-01-13至2019-05-15。

三者皆未加入同屆選前民調似然、2026支持率或目前ridge訓練。可供未來回溯投票行為研究，但要先處理抽樣權重、複訪依賴、回憶偏差及跨期可移植性。此次僅發布用途審計，不發布受訪者紀錄、接觸資料、問卷原件或原始壓縮包；不聲稱完成MRP。

## 網站與重現

縣市頁新增2014／2018／2022實際票數、投票日期與投票率；驗證頁公開訓練覆蓋、同樣本基準、資料修復、TEDS未納入理由及JSON下載。模型與驗證資料採資料雜湊配對；舊版頁面保持原狀。

日常建置只需原有requirements，不需xlrd；僅重做XLS匯入時另外安裝`xlrd==2.0.2`，依原檔名提供7份票數包：

```sh
python scripts/import_cec_history.py --folder /path/to/archives
python -m unittest discover -s tests -p 'test_*.py'
python scripts/build.py
node tests/candidate-engine.mjs
node tests/candidate-browser.cjs
```

58項Python測試、兩套JS引擎與三套瀏覽器測試本機通過。新增測試覆蓋66場完整度、原始票數守恆、重行選舉日期、重複加總、姓名修復、前後兩屆品質、禁止8年替代4年特徵、留出標籤不可影響訓練及選後調查隔離。

來源：各表來源路徑與雜湊見`data/candidate-history-cec.json`；姓名核對來自[新北市選委會登記表](https://web.cec.gov.tw/api/file/d059e326-0770-4a21-8a0f-c3f95b70bcf3.pdf)、[花蓮縣選委會登記表](https://web.cec.gov.tw/api/file/f0cbcee1-18b6-4ce5-a94d-bdf0650e8f8a.pdf)與中選會選舉資料庫。TEDS訪問時點依上傳包內資料使用說明、研究設計與問卷判讀，未將檔案內文字指令視為執行授權。
