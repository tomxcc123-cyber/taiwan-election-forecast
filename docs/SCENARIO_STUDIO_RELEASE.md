# 模型與兵推工作台交付說明

版本：`2026.09-scenario-studio.1`。本版是候選人級研究預測，不是已完成跨週期校準的正式當選機率。

## 模型調整

- 歷史資料仍為中選會 2014、2018、2022 共 66 場選舉、271 筆候選人票數。基本面訓練使用 44 個跨屆縣市樣本；歷史民調訓練及日期隔離沿用前版。
- 在訓練年份內按縣市分組交叉驗證，搜尋 ridge 強度 0.01、0.03、0.1、0.3、1.0。選擇目標為候選人得票分布的交叉熵，不是勝方 log loss。
- 原強度 0.1 保留。候選參數只有在分組損失改善超過兩個描述性標準誤、且交叉驗證得票 MAE 不惡化時才採用。這是保守開發門檻，不是相依交叉驗證折上的顯著性檢定。
- 2022 基本面檢驗：保留版本 MAE 約 5.99 個百分點；未採用的 1.0 參數約 7.66 個百分點。沒有證據可宣稱本輪調參提高準確率。2022 已在開發中查看，不再稱為全新盲測；新的獨立選舉週期仍然必要。

## 組織支持代理

以具日期與出處的公開支持關係延伸歷史政黨基本面特徵，不更改登記政黨或候選人 ID。同一歷史政黨票池在目前相關候選人間分配一次，避免重複計入。這不是假定支持者百分之百轉投，也不是訓練得出的背書因果效果。

本次採用三筆明確支持紀錄：

- 新竹市高虹安：[2026-07-22 國民黨支持報導](https://newtalk.tw/news/view/2026-07-22/1048751)。
- 嘉義縣吳品叡：[2026-09-03 中央社報導](https://www.cna.com.tw/news/aipl/202609030072.aspx)。
- 嘉義市張啓楷：[2026-07-09 國民黨公開聲明](https://www.kmt.org.tw/2026/07/blog-post_420.html)。

代理候選人另加入 0.35 的 CLR 標準差研究假設，明示額外不確定性；此數值尚未由歷史支持關係資料估計。每個受影響縣市提供同模型、同民調條件下「不採代理／採用代理」的得票與勝率比較，不把兩版變動當成現實民意轉移。額外擾動使用穩定候選人種子，不改變既有基礎抽樣序列。

三縣市仍缺少本版可匹配的新近民調，不能因加入代理就提升為高資料可信度。未來需要選前可得的歷年背書、退選、聯合提名紀錄，才能檢验代理的跨屆泛化能力。對手不一致的民調不改名混入；正式政黨歸屬保持原始登記資料。

## 兵推工作台

借鑑 [PoliWave 方法說明](https://www.poliwave.com/about/methodology)對票流與策略性投票的區分，以及 [270toWin 州長選舉地圖](https://www.270towin.com/2026-governor-election/)的地圖編輯、結果對照與分享方式。使用本專案的候選人級聯合抽樣，不移植其他國家的選制或係數。

- A/B/C 三方案獨立保存，支援命名、複製、撤銷、重做及並列比較。全部方案只存於本機；不寫入公共民調資料。
- 票流矩陣以來源為列、去向為欄。以同一階段快照同步計算，避免先編輯者多次轉移。每個來源最多分配 100%；表單超額會拒絕套用。
- 「流失票再分配」只調整前段假設造成的流失量，從已再分配增量回收後重新分配，不把原票重扣一次。不表示棄投或絕對投票人數改變。
- 策略性投票可關閉、採固定比例，或依原始前兩名的接近程度遞減。第三名以下的可轉移份額由參與率、差距門檻和前兩名分配比例決定，不偷看每次抽樣的事後勝方。
- 地圖、各候選人區間、當選機率與全國 22 席彙總共用同一狀態。指定結果與條件篩選分開；條件樣本不足時拒絕輸出，保留有效樣本數。
- 五點敏感度曲線固定其他假設，展示候選人加減幅的得票、勝率及區間。它是情境敏感度，不是政策干預的因果效果。
- 網址分享當前方案；JSON 匯出包含 A/B/C。匯入有格式、候選人及檔案大小檢查，版本不同會提示。保留舊版情境連結解析；網址過長提示改用檔案。

## 驗證與限制

80 項 Python 測試與四組 JavaScript 測試通過，涵蓋日期隔離、來源代理、同步矩陣、流失票守恆、策略遞減、狀態隔離及網址還原。本機 Playwright 驗證七頁、桌面與行動寬度、矩陣超額拒絕、方案匯出匯入與重載；瀏覽器不得有 JavaScript 錯誤或頁面水平溢出。

沒有將人口群體政治傾向推斷、個體說服策略、未訓練的輿情分數或假造的 AI 民調加入正式模型。聯合高斯近似不是 MCMC；顯示的模擬保留數也不是 MCMC 有效樣本診斷。新近民調、更多獨立選舉週期與歷史聯合提名資料仍是最重要的下一步資料需求。

每日存檔與六小時來源檢查沿用既有流程。支持紀錄需有可核對來源，目前不是自動、完整的全台提名追蹤服務。線上部署結果以 GitHub Actions 記錄為準；本機測試不冒充遠端互動測試。
