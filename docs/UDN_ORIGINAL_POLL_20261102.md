# 聯合報系民意調查中心：2026-11-02 原創民調入庫核驗

## 原因與修正

先前僅以「聯合報是新聞刊載媒體」的規則排除同名來源：該規則對*轉載其他機構民調*適當，但錯誤排除了**聯合報系民意調查中心自行執行**的原創調查。原有7個pollster的registry中沒有UDN；定時工作只掃既有TVBS／美麗島等源，也沒有UDN原創新聞的first-party discovery。當前修訂增加 `udn-poll-center`，原始報告頁面人工核驗後以 `reviewed_multi_source_methodology_partial_response` 入庫，新聞轉載不新增pollster。

兩份資料均為住宅電話加手機雙電話尾數隨機抽樣，95%信賴水準抽樣誤差約±3pp；台北性別／年齡／行政區加權，高雄性別／年齡加權，均由聯合報出資。高雄其他報導有「調查至10月30日」簡寫，以上採用**聯合報原始報告所述10月31日**。調查公布的樣本量不代表投票意向題每個回答子樣本已逐項公布。

## 入模邊界

- 保留未公開的1pp為 `response_mass_unreported`，不用「其他候選人得票各分多少」、「未決定率+1%」等人為填補；兩位主要候選人的**相對支持度觀測**可以用於已實作的候選人 joint likelihood。
- `model_eligible=false` 是舊版三方分類器的註記，不能誤讀為 HB-TLEF v5 的未入模判斷；v5以 `model.polling.match_records`的`poll_audit[].included`及候選人名單比對為準。
- 不把「誰看好當選」(台北蔣48%、沈35%；高雄賴49%、柯21%)或滿意度當成投票支持度，也不當成實際投票率。
- 不給UDN額外特殊權重；模型沿用現行非TVBS同類測量誤差設定。這兩份不能證明勝選概率校準。
- 沒有證據驗證原始調查的未公布分層、非回應偏誤與機構house effect；不因新增兩份就宣稱全台推估準確度已提升。
- `data/pollster-registry.json`的UDN一方民調儀表板為 **queue_only** 監看，發現新URL只入人工審核佇列，**不自動從文字百分比入模**。如果原站封鎖或版型改變，必須在來源覆蓋顯示失敗，不可默認無新民調。
- 本資料版採2026-11-02修訂，不宣稱已把未來所有《聯合報》調查自動審核／入模。
