# 投票率影子模型：固定公式、時間順序、風險約束

更新：2026-10-28。類型：歷史已知資訊的固定公式回測，**不是正式2026投票率預測或政黨得票預測**。

## 一、為何繼續

前輪使用中選會2014／2018／2022年縣市長選舉原始資料，逐投開票所驗證候選人票數，構建2018→2022年366個具同碼同名的行政區配對，2022年嘉義市因不同投票期或原始來源限制未強行配對。正式2022留出下，2018投票率直接延用的選民數加權MAE=6.2273pp，沿用2014→2018縣市完整舊趨勢的MAE=6.9655pp。行政區觀測投票率與兩黨得票變化的事後縣市內相關僅−0.04879；不支持把它當成2026候選人當選率的直接修正。

網站既有HB-TLEF的正式得票率、勝選機率、22縣市聯合模擬與Polymarket實驗權重均保持不變。本次只建立可重現的影子參與率預測「模型比較」。

## 二、2022年前可觀測特徵

預測單位為2018—2022同碼同名的行政區，資料核驗由原有資料源SHA、縣市票數對帳與2018、2022雙時間點篩選保障。

所有模型輸入嚴格限於2014、2018已公布的歷史：
- t18_town：該行政區2018年投票數／選舉人數。
- t18_county：該縣市2018年投票率。
- drift_county：同一縣市2018年投票率減2014年投票率。
- drift_national：全台2014→2018投票率差（分別先對全台選民數及投票數加總，再計算比率）。

**2022年資料只在留出評分階段出現**；樣本外誤差按2022年真實選民數加權。這個加權分母只為事後比較，不允許用作模型預測特徵。

## 三、固定的七組公式

預測值（均截斷在1%—99%）：

1. persistence：t18_town。
2. county_shrink_75：t18_county + 0.75×(t18_town−t18_county)。
3. county_shrink_50：t18_county + 0.50×(t18_town−t18_county)。
4. county_drift_25：t18_town + 0.25×drift_county。
5. national_drift_25：t18_town + 0.25×drift_national。
6. shrink_75_drift_25：t18_county + 0.75×(t18_town−t18_county) + 0.25×drift_county。
7. county_drift_100：t18_town + 1.00×drift_county（作為前輪再現檢查）。

上列0.5、0.75及0.25等權重是可解釋的固定研究情境，**不是經過2018以前資料估計出的最優權重**；研究者在本實驗前已經看過2022結果，因此若某公式表現最好，也只是同一留出集上的**事後探索**，不是第二次獨立樣本外證據。

## 四、績效與不確定性

- 與前輪2022留出資料同時檢查：persistence的MAE與RMSE若不能重現至容許的四位小數，停止輸出。
- 同一366個行政區的選民數加權MAE、RMSE、偏差；每縣市MAE／RMSE及其相對基準是否下降。
- 針對21個縣市做1000次確定性重抽樣，每次完整抽出同一縣市內的所有行政區，計算影子模型與persistence之加權MAE差；呈現90%分位範圍。這只反映同一2022留出樣本中「縣市群集間」的異質性，**不等於跨年份的信賴區間，不構成顯著性宣稱**。
- 禁止讓2022實際投票率、候選人勝負、2022選舉人數或其他後驗特徵進入影子模型公式。對2022因變數做測試擾動，模型預測必須不變。

## 五、可升級性判準

即使2022上的某組固定公式表現超過persistence，仍然不能自動上線為2026正式模型：
- 只有一屆2022真正可用的行政區留出，缺乏獨立的跨選舉週期驗證；邊界代碼與名稱相同不等於村里界／投票人口相同。
- 不能在同一2022樣本上評分、選權重、再把選中的結果宣稱為新的樣本外證據。
- 投票率的宏觀預測不等於投票選擇聯合模型；尚缺乏可驗證的「投票率變動→候選人支持份額變化」的因果或預測增量證據。

腳本與靜態頁面皆帶有 fail-closed promotion_gate.status='blocked'，且不修改HB-TLEF正式預測。

## 其他修正

2026年10月28日全站GIS瀏覽器測試已通過，之前HB-TLEF v5發版最後一項失敗是固定假定「新北市Pearson Data恰好只有一份民調」的過期測試。源資料如今包含兩份不同時間且ID不同的紀錄。新驗收改查**特定可信來源唯一**，以及**同縣市民調ID沒有重複**，允許合法更新並保持嚴格來源可追溯性。
