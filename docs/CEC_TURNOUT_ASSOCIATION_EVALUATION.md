# 中選會候選人逐站得票、投票率關聯與時間順序留出檢驗（2026-10-28）

## 研究問題

投票率是否提供**可被驗證的額外預測訊號**？不能直接將「投票率提高」等同於特定候選人或政黨得票率提高。本研究將官方投開票所候選人得票、投票數和選舉人數在相同行政單位內對齊，並在正式 HB-TLEF 之外進行描述性研究。

原始來源：中選會開放資料 https://data.cec.gov.tw/選舉資料庫/votedata.zip，使用每屆縣市長選舉的 elctks.csv（候選人得票）、elprof.csv（總投票、有效票、無效票與選舉人數）。既有候選人歷史檔 data/candidate-history-cec.json 的各候選人縣市總票數是獨立核對的比較標準。

## 核驗和研究樣本

scripts/build_cec_candidate_turnout_panel.py 必須通過四層實際資料檢驗：

1. 逐投開票所同場候選人號次與票數齊全，並同時匹配 elprof.csv 原始站點六欄地理鍵。
2. **每站各候選人得票數加總等於該站有效票數**，同號選票不可重複。
3. **所有站點各候選人得票數加總等於原始已核驗的縣市候選人得票數**，站點按行政區代碼聚合後仍與每個鄉鎮的投票率面板有效票吻合。
4. 2018、2022年同縣市、同行政區代碼與中文名稱相同才配對。2014年的部分村里／區級名稱不完整，不能用2022年的行政界直接回填2014。2022嘉義市長選舉的單獨投票期及缺乏同場逐站核對結果，維持排除狀態。

正式資料執行結果：2018—2022年共有366個可比行政區、21個縣市。338個行政區、18個縣市同時具有兩屆國民黨及民進黨候選人的可比兩黨得票分布；其餘28個行政區不合資格，不能用「缺席政黨得票為零」的方式假造跨年競爭。

注意兩黨得票分布衡量的是實際已提名候選人的得票，不能將同黨不同候選人視為品質相同，更不能由投開票所總票數推斷某個選民的投票行為。

## 真正的選前時間順序留出

scripts/evaluate_turnout_holdout.py 固定 **2022年為測試年份**，兩個投票率預測方法僅使用2018年已公布或更早的原始資料：

- 延用2018：2022每區投票率 = 2018年該區投票率，沒有自由參數。
- 2014—2018縣市舊趨勢：2022每區投票率 = 2018年該區投票率 + 該縣市2014→2018投票率變動（僅以前兩屆縣市總數估計）。極端值被限制在1%至99%。

**禁止使用2022年已觀察到的投票率、2022年政黨得票率或2022年行政區平均差額訓練上述預測。** 使用2022年的選舉人數只為*事後計算誤差權重*；這是評分方式，不是預測輸入。

本次核驗後的366個行政區、21縣市：

| 方法 | 2022選民數加權平均絕對誤差（MAE） | 2022選民數加權均方根誤差（RMSE） |
|---|---:|---:|
| 2018投票率直接延用 | 6.2273 pp | 7.4828 pp |
| 加2014→2018舊縣市趨勢 | 6.9655 pp | 9.4523 pp |

2018延用法比舊趨勢法的MAE低0.7382個百分點。**僅有2022一屆真正留出結果，不能宣稱未來跨屆仍然如此，也不能把此MAE當作候選人得票率誤差。**

## 選後觀察性的關聯（不可當作預測係數）

只對兩屆均有KMT、DPP候選人參選且選票完整對帳的行政區，觀察：

- 2018→2022年投票率實際變化（百分點）
- 2018→2022年KMT在KMT＋DPP兩黨有效票中的占比變化（百分點）

計算對每個縣市去平均、再用2022年實際選舉人數加權的**描述性** Pearson 關聯，不用任何2022年資料來聲稱2022選前可預測性。338個行政區，18縣市：關聯係數 **−0.04879**。

這不是投票率的因果效果，也**不是**2026年任何政黨的預測修正係數。縣市內仍有候選人更替、現任者因素、地區人口結構和公共政治事件等未控制混淆因子。使用2022實際投票率來預測2022選舉結果是資訊洩漏，不能作為模型績效證據。

## 發布規則

- **正式2026 HB-TLEF、GIS、市場融合和聯合模擬均不變。** 另行展示歷史驗證。
- 來源輸出：data/cec-town-candidate-association-2018-2022.json、data/turnout-holdout-2018-2022.json。
- API 和網頁的研究標記為 historical / no_causal_claim / official_forecast_unchanged，任何不合格式或不合格的紀錄須拒絕渲染。
- 若後續要檢驗候選人勝率增益，須先建立2014—2018全同域得票／投票率歷史前測資料、選前可觀察的投票率解釋變量及獨立年份留出，並以原HB-TLEF對照基準衡量Brier、MAE與校準；不可把同一年選後的行政區關聯用於當年的選前預測。

## 再現

- 票數校驗：python -m unittest tests.test_cec_town_candidate_panel -v
- 固定年份的留出／洩漏測試：python -m unittest tests.test_turnout_holdout -v
- 原始中選會ZIP到行政區候選人資料：python scripts/build_cec_candidate_turnout_panel.py --zip PATH_TO_VOTEDATA.ZIP
- 歷史評估：python scripts/evaluate_turnout_holdout.py
- 網頁：?view=turnout 「投票率與歷史選舉得票：來源核對與留出測試」。
