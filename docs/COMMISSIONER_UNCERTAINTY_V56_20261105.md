# 委託方層級的民調不確定性處理（2026-11-05）

## 討論起點，不預設政治方向

信民兩岸研究協會委託、畢肯執行的10月28—30日台中調查記錄何欣純41.1%、江啟臣30.4%、洪麗華0.7%、未表態20.8%、不投票／廢票7%。此為**原始投票意向資料**；不是報告作者另行推算的選舉日得票率，也不能不經多期歷史誤差分析就推定調查機構具有已知正向民進黨的偏差。

2026年1月畢肯為美麗島電子報執行的同選區調查（江啟臣43.9%、何欣純29.4%）與10月結果方向不同。月份、委託方、題目及選情變化都可能影響差距，故**不能直接把兩次差距認作委託方偏差大小**。同年10月底另一份國民黨議會黨團委託的民調也有相反方向差距；不同委託方同樣需要一致、非選擇性的來源規則。

## 新的統計設計

已存在的候選人聯合高斯模型用樣本量、設計效應、未表態／未公開回答、候選人題目完整性、時間差與執行調查機構（pollster）相關 house effect 形成測量協方差。本次在**執行調查機構之外**加入明確的 *commissioner/委託方* 元資料：

- `commissioning_type = external_commissioned`：來源及執行方與委託／出資方分開且身份可核實的調查。
- `commissioner_id`：同一委託方固定鍵，供跨波次相關誤差使用。原始支持度和委託方名稱不修改；委託方不被誤認作 pollster。
- `in_house`：調查中心自行執行的自有發布調查（如 TVBS、聯合報系民調中心、ETtoday）。
- `undisclosed`：當前來源未能核定委託身份時不猜測；仍受原有 pollster house effect 及其他品質約束。

對各外部委託方在對數相對支持尺度的觀測協方差增加：

`R_total = R_sampling + R_pollster + R_time + R_question + sum_c (sigma_commissioner^2 * L_c * L_c^T)`

其中`L_c`為同一委託方各題目的政黨對比載荷，**均值永遠為零**，不涉及藍綠方向或支持度強制扣減。相同委託方多波訪問共享該誤差；不能因多次發稿將同一委託來源誤認作完全獨立的資訊。

目前 `sigma_commissioner = 0.20`。這是有版本紀錄的**敏感度／保守誤差假設**，不是經台灣跨機構充分回測得出的最佳參數。它是 log-support contrast 的標準差，**不是民調乘0.8，也不是扣除20百分點**。最終影響由完整協方差矩陣、其他民調、先驗、時間與候選人對比決定，無法概括成每份民調一個固定百分比權重。

對信民、凱達格蘭基金會、震傳媒、鉅聞天下與美麗島電子報等已核定外部委託來源，適用**完全相同的規則**；TVBS、聯合報系民調中心等自辦來源保留現有機構／方法不確定性。存檔舊波次按驗證過的`(pollster_id, funding)`配對補充元資料，新爬取波次在資料入口即填入相同元資料。

## 公開可重現的敏感度分析

`model/commissioner_audit.py` 對每次正式發布的候選人後驗結果執行**只讀**對照：
1. 全部民調照常納入但將委託方額外標準差設為0（舊參數對照），辨識新假設對各地中心值的影響。
2. 每次將單一`commissioner_id`的全部已納入調查波次移除，重算其他條件完全相同的後驗平均得票，列出各候選人差距（leave-one-group-out）。

兩種對照都**不會改寫正式預測資料，不會改動原始民調**；後者是來源影響敏感度而非已證實的民調偏差或對當選結果的反事實因果估計。所有外部委託方均可看到同一格式的檢查結果，而非只針對信民協會。資料與模型快照同時存入公開`candidate-model.json`，網站來源觀測站顯示對照表。不存在固定80%權重。

## 如何驗證、如何繼續

單元／迴歸測試涵蓋：

1. 模擬支持率60:40與40:60，檢查委託方不確定性的均值處理方向完全對稱，禁止因支持某政黨而扣分。
2. 相同抽樣及調查機構條件下，加入委託方誤差應降低**單份外部委託民調的後驗拉動**、增加後驗協方差。
3. 自行執行的調查在新開關前後結果不變。
4. 相同委託方多波次相關處理，比不同委託方的獨立樣本更不易讓模型過度確信。
5. 未提供委託方 ID 的`external_commissioned`紀錄無法靜默入模。
6. 固定較早時點不偷用11月3日才發布的信民資料。

**尚未完成、也不應宣稱**：針對台灣所有委託機構分離估計有方向的偏差、估計可跨選屆轉移的委託方誤差參數、用2026選舉結果做事前回測，或證實某協會具有穩定政治傾向。需要收集足夠多不同選區、相近日期、同方法問項且有最終得票標記的歷史調查，做按選舉年度留出的校準與評估，才可從零均值誤差改為可驗證的有向 house/commissioner effect。
