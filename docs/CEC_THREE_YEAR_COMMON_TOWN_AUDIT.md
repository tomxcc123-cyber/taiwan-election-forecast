## 1. 問題與來源

此前已建立2014→2018年 **366個鄉鎮**、2018→2022年 **366個鄉鎮** 的兩套行政區投票率留出研究。這不是一個同樣366個鄉鎮連續三時點樣本。本次直接從以下經中選會原始逐站票數核驗的檔案重建交集：

- `data/turnout-district-panel-2014-2018.json`：2014當屆 `elbase.csv` 的官方行政區名稱，以及2014、2018逐站總數核對。
- `data/turnout-district-panel-2018-2022.json`：2018、2022兩屆已對帳的鄉鎮資料。
- `data/turnout-two-cycle-town-validation.json`：時間順序固定的2018、2022歷史留出誤差；此檔`promotion_gate.status=blocked`。

原始選舉數據來源：中選會 [選舉資料庫](https://db.cec.gov.tw/) 及 [官方開放資料](https://data.cec.gov.tw/選舉資料庫/votedata.zip)。

行政界的後續外部核對來源：國土測繪中心 [歷史鄉鎮市區界](https://maps.nlsc.gov.tw/pro/013_41_layer.html) 有特定年份版本；[鄉鎮市區界線開放資料](https://data.nat.gov.tw/dataset/7441) 提供TOWNID、TOWNCODE、COUNTYNAME等欄位。但本次**尚未下載、對齊和逐年重疊分析選舉當期多邊形**，不可把站數相同、代碼與名稱相同視為歷史空間完全一致。

## 2. 已完成的跨原始檔核對

取交集只要求同縣市、同鄉鎮代碼、原始中文名稱一致，**不**跨年對接投開票所編號。共同樣本要再次核對2018在兩份不同來源面板的全部5項整數：選民、投票、有效、無效、站點數。不一致則直接報錯，不生成分析。

核對結果：

| 指標 | 結果 |
|---|---:|
| 2014→2018既有配對 | 366 |
| 2018→2022既有配對 | 366 |
| 三屆共同樣本 | **364** |
| 共同樣本縣市 | **21** |
| 兩份面板2018全部5項數值衝突 | **0** |
| 站點數三年都相同 | **112** |
| 至少一個4年周期選民數變動幅度大於8% | **38** |
| 站點數都相同且選民數兩周期變動不超過8% | **105** |

僅出現在2018→2022兩屆配對、未通過2014→2018原有配對的行政區包含彰化縣員林市、苗栗縣頭份市；不自行回填。2018→2022原面板亦未納入2022嘉義市另期的不可比逐站資料。

**重要：** 8%是額外的探索性資料品質觀察門檻，非從歷史地理變動驗證出的官方標準。人口自然遷移、選舉權資格、行政界微調均可能影響選舉人數；投開票所數變動亦不能單獨說明邊界變動。資料只支持「未經幾何核驗的同碼同名匹配」。

## 3. 固定模型於真正共同樣本的留出誤差

下表全部使用**同一批364鄉鎮**，但2018與2022各自按該屆實際選舉人數加權，不可把兩期誤差合成一個獨立信賴區間。

| 共同樣本364鄉鎮 | 直接沿用上屆 MAE | 向縣市均值收縮25% MAE |
|---|---:|---:|
| 預測2018 | 3.50287 pp | **3.43862 pp** |
| 預測2022 | 6.25004 pp | **6.21024 pp** |

收縮帶來的改善分別是0.06425pp、0.03980pp，幅度很小，不能宣稱此方法穩定改善未來選舉精度，更不能轉換為候選人勝選率增益。

另外以站點數是否改變、選民數變化是否小於8%形成四組**事後**診斷樣本，網站可查看各自的歷史分數。此處分組變數依賴留出年份選後才可得的資訊，所以**按分組後看見的改善是選擇偏差風險，不能當成真正獨立的選前模型提升**。只有固定兩屆原本的前一屆投票率預測公式，在沒有使用當屆實際投票率特徵的情況下才可稱為時間順序歷史留出。

## 4. 與候選人投票選擇模型的距離

本審計沒有候選人或政黨得票作因變數，所以：
1. 沒有證據足以把投票率當成候選人得票份額的直接係數。
2. 2018→2022年338區、18縣市的描述性兩黨得票生態關聯只能保留研究標記，不能宣稱因果關係。
3. 要推進候選人得票的跨期增益驗證，須補齊2014年鄉鎮候選人票數與2018年同口徑核對、歷史多邊形與行政界變更，然後**先固定選前可觀察特徵及比較基準**，按2018／2022分別留出；Brier分數只能用獨立勝負概率而非投票率MAE替代。
