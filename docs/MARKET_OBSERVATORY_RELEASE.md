6. 遵守原網站保守選前發布暫停機制。scripts/build.py 只有在允許發布期間才產出 market-snapshots.json；禁止新功能繞過全站資料暫停。

## 守則與限制

- **沒有將市場價格納入 HB-TLEF 推論、候選人支持率或正式得票預測。** 原模型及其勝率校準問題均保持不變。
- Polymarket 的每個 Yes 合約是交易價格，依有效交易、市場規則及流動性決定；同一事件數個 Yes 合約不一定精確加總為100%。資料可能缺漏、過時或受交易地理限制。
- Gamma 端點公開，不需要登入；讀取僅限 HTTPS gamma-api.polymarket.com 的事先核對事件 slug。每日歷史資料只從實際已接收到的快照構建，不補造過去報價。最多保留每合約 90 個樣本，不等於完整市場分鐘歷史。
- 公開選舉市場的結算規則依合約而異，不能把政黨勝出合約、縣市長候選人合約混用。姓名對照表不是自動判定身份；未核實的名稱不顯示差額。
- 全球市場資料並非台灣選民的代表性意見，且不是常規民調。觀察資料不能據此作精確投票人動員或政治說服推斷。
- GitHub Actions 排程無即時性保證。未來欲增加跨年、村里、立法院或更細GIS資料，仍須先蒐集經選委會核對的歷史資料及行政邊界版本；本次沒有捏造或直接外推其他選制。

## 市場融合研究分支（新增於 2026-10-28）

此功能不是單純展示市場差額：在市場觀察頁新增 **融合試驗勝率**，確實由 HB-TLEF 模型對該縣市每位候選人的勝率與 Polymarket 的已核驗 Yes 合約價格計算不同的事件結果機率。預設研究權重為5%，可切換0%、5%、10%。這些是預先聲明的敏感度假設，不是從歷史表現訓練或聲稱優化的係數。獨立正式預測仍採原模型，跨縣市共同震盪與全國席次不被此單縣市研究轉換改寫。

若市場選項對應完整，在各候選人的勝選事件上採用歸一化對數概率融合：

\[p^*_{c,i} = \frac{p_{c,i}^{1-\lambda_c} q_{c,i}^{\lambda_c}}{\sum_j p_{c,j}^{1-\lambda_c} q_{c,j}^{\lambda_c}}\]

其中 p 為模型條件勝率，q 為市場 Yes 價格整體對齊之後的研究分布，λ 為市場權重。這不是投票支持率模型；未報告選項只按保守規則分配剩餘權重，未核驗姓名絕不猜配。有限抽樣產生的零勝率只在研究合成時作極小的數值平滑。此概率組合**不保證校準**，也不代表市場交易者提供對民調獨立的新信息。

僅符合以下門檻的來源才產生實驗值：報價距頁面檢查不超過12小時；累計成交量和流動性均不少於1萬USD；至少兩位主要合約候選人已核實對應當前名單；未配對合約的價格總量低於2%；所有 Yes 合約報價總和在93%到107%；已配對合約至少90%；主要合約買賣價差可核對且小於10個百分點。否則只展示原始資料及排除理由。門檻均屬工程性保守預設，沒有回測推論。

真正將市場訊號放進**正式聯合預測**，需要先做到：保留市場逐時快照與來源時間、處理同一民調在模型和市場被重複利用的相關性、取得足夠具不同年份的結算事件、按預先固定權重比較 Brier/log loss 和校準曲線。無證據不能只憑市場流動性較高就認定市場更準。入模時還須聯合更新各縣市模擬而非各自調整勝率後拼湊全台席次。

新模組：`site/market-fusion.mjs`；回歸測試：`node tests/market-fusion.mjs`。

## 聯合市場訊號研究分支（2026-10-28 第二階段）

原有市場融合只在縣市內採對數意見池（0%／5%／10%），無法保持跨縣市候選人贏家事件之間的相關性，也不能據此直接拼成全台22縣市長選舉的席次分布。新增 \`site/market-joint-shadow.mjs\`，保留生產 HB-TLEF v5 之**同一索引的2,000條聯合 Monte Carlo 路徑**，對每條模擬路徑進行研究用途的重要性重加權。**這是各縣市長席次，不是立法院113席。**

對模擬路徑 \`s\` 與品質審計合格縣市 \`c\`，依該路徑勝選候選人的模型事件勝率 \`p[c,w_s]\`、市場候選人合約對齊分布 \`q[c,w_s]\`，取預先聲明的實驗權重 \`λ∈{0,0.05,0.10}\`：

\`\`\`
log_weight[s] = λ * Σ_c log(max(q[c,w_s], 10^-6)/max(p[c,w_s], 10^-6))
weight[s] = exp(log_weight[s] - max(log_weight)) / Σ exp(log_weight - max(log_weight))
ESS = 1 / Σ(weight[s]^2)
\`\`\`

以標準化的路徑權重計算各縣市候選人勝出事件、各政治分類的縣市長數均值、5%／95%區間、至少12縣市數的機率。原本的各縣市聯合依存關係，由原始共同模擬索引保留；不進行各縣市單獨重抽再拼湊。若某個市場未通過原來的流動性、合約匹配、時效與價差門檻，則該縣市完全不參與權重修正。

**額外的獨立保護：** 凍結時間必須在來源市場檢查時間之後，不能使用未來報價；要求22縣市完整且等長模擬，抽樣結果有效且每個候選人ID可匹配；所有路徑非負。重要性加權後如 \`ESS < 20% * 模擬數\`，或最大單一路徑權重超過5%，則只顯示拒絕原因，不輸出研究席次，以避免極端不穩定。前述門檻仍屬保守工程預設，未經歷史選舉調參。

此方法具有限制：市場價格受相同民調與媒體消息影響；事件合約並非獨立對數似然，模擬分布之加權更新不是具經驗校準的 Bayesian posterior，也不保證各縣市的樣本外準確率提高。尤其在基準模型沒有抽到某候選人勝出的情況，對應市場無法在此模擬支撐上憑空創造新的勝選路徑。正式 HB-TLEF 的得票率、候選人勝率、共變異結構和網站預設GIS完全不變；另列 \`joint_05\`、\`joint_10\` 研究摘要與 ESS 審計。

每日配對 \`data/market-fusion-history.json\` 亦新增兩組聯合實驗的期望縣市數、候選人層勝出概率及 ESS；原有舊日期檔案不回填新方法。選後評估將在官方結果可核對後，針對每個研究權重與**同一日期、同一縣市**的基準概率做配對的多分類 Brier、Log Loss 差異；所有估計樣本數單列，不把不同日期視為獨立選舉。
