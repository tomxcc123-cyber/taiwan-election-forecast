# 候選人聯合預測網站成品

本文件保留初版紀錄；目前主站的官方票數重訓與驗證請見 [CEC_RETRAINING.md](CEC_RETRAINING.md)。以下舊資料限制與樣本數不代表新版資料狀態。

版本：2026.09-candidate-joint.1。這是已可部署的研究產品，不是已校準的正式預測服務。

## 本次完成

- 主頁、縣市、民調、情境、驗證、方法全部切換為候選人級資料。登記名單逐人建模，先決定各縣市勝方，再按政黨/身分加總22席。
- 民調按姓名與名單精確配對（僅NFKC字元正規化），不使用舊版藍白陣營標籤決定對象。姓名字形尚未核對的不強行匹配。
- 新基本面以歷史資料重新訓練，未使用六月舊預測作標籤/先驗；因此可使用早於六月、但晚於訓練週期的原始民調，不重複吸收六月預測中的資訊。
- 不同報告可共同更新。重疊訪問日期或同份報告題目保守去重；同機構的相關偏差透過共享協方差處理，不把每次發表當成新的独立大樣本。
- 候選人中心化對數空間及正交對比避免任選分母造成不同結論。權重使用加權百分比的近似測量協方差，不杜撰原始票數。
- 當前共享全台/區域/地方狀態接受民調聯合更新；與其他縣市的相關性進入推論，不只在最後額外加噪音。
- 訪問區間中點到資料日期採反向隨機漫步協方差，未來到投票日的變動另計。沒有第一份弱民調到來就突然扣除舊資料不確定性的跳躍。
- 支持變化、指定候選人的選票轉移、策略投票、指定席次與真正條件勝選可互動。策略排名用基準訊號，不偷看每次抽樣的未來勝方；條件模式同步篩選全部縣市並檢查至少100次有效樣本。
- 自動抓取後重新訓練、推論、建置；模型與民調版本配對失敗則保留最後有效頁面。分享、快照下載、行動版及鍵盤地圖操作均有測試。

## 數學實作

先前ridge與縣市群集bootstrap產生的log-share抽樣，在賽事內中心化後取聯合均值 m、共變異 P。這一步把非高斯bootstrap混合分布近似為高斯，可能損失尾部分布形狀。

對每份題目以正交對比矩陣 H 形成 z = H log(q)，再用候選人選擇矩陣組成 A。未列人選不作零支持，只有所列人選的相對效用被直接觀測。這隱含相對支持可由題目移植至完整名單的假設，並非對選項效應的識別估計。

測量矩陣 R 包含設計效應折減的抽樣近似、未表態/部分對決誤差、同機構具名政黨相關誤差與訪問日期之間共享的反向隨機漫步誤差。機構偏差積分消去而非逐份報告獨立估計；沒有足夠資料把機構/訪問模式/母體的影響可靠分開。

```text
S = A P A' + R
m_post = m + P A' solve(S, z - A m)
P_post = P - P A' solve(S, A P)
P_election = P_post + Q × days_to_election
```

NumPy線性解法及對稱特徵值分解用於計算與半正定檢查。均值與抽樣在各候選集合中softmax閉合；發佈抽樣精度為百万分之一，再標準化。瀏覽器使用同一批抽樣重新計算情境，不各模組各算一套勝率。

## 驗證與未完成項目

1. 基本面模型保留2018訓練、2022整屆留出，以及預先指定的正則化敏感性。
2. 新的同一聯合引擎另做無民調、零外推的2022留出比較，公開與簡單延續基準相同目標/相同樣本的分數。這不是提前180/90/30/7天的回測。
3. 新動態民調似然目前只有程式與數學一致性測試，缺少歷史選前民調快照來驗證實際預測能力。不能把第1或2項分數宣稱為加入民調後的準確率。
4. 只存在一個留出週期，部分歷史資料為截短名單。Q、house_sd、未表態與部分對決誤差等是明示假設，尚非跨週期估計。沒有實作完整MCMC超參數後驗、MRP、因果投票模型、有效的ML集成校準或可靠的日間歷史勝率曲線。
5. 登記名單狀態為已登記、待資格審查。政黨轉換、未有同名歷史與未有直接民調會明示；这些欄位不等於已識別因果效果。不能因某縣市模型機率高就宣稱它真的確定當選。

本次使用者授權的是將候選人研究模型整合為可用網站，因此 `research_publication_allowed=true`；`calibrated_forecast=false`。沒有將先前未通過的校準/官方完整資料閘門改成「已通過」。舊第一階段產物仍留存，不篡改歷史記錄。

## 成品使用

線上網站由GitHub Pages提供；`dist/`是直接可部署的靜態網站。完整包另外包含模型源碼、輸入JSON、測試和資料來源說明，排除個人原始試算表、教材PDF、原始民調快取與憑證。

本機只看成品：

```sh
python scripts/serve_product.py
```

重新計算：

```sh
python -m pip install -r requirements.txt
python -m unittest discover -s tests -v
python scripts/update_polls.py
python scripts/build.py
node tests/candidate-engine.mjs
```

原始來源没有新民調，不會產生新的觀測。文字解析規格有重大變動時仍可能需要維護。排程非即時SLA，已下載檔案、CDN快取、公開Git歷史不能撤回；選前暫停發佈維持既有保護。

## 方法來源

- [Heidemanns、Gelman、Morris，2020，動態選舉模型](https://sites.stat.columbia.edu/gelman/research/published/Harvard_Data_Science_Review.pdf)：參考共享狀態及機構效應設計，不搬用美國係數；原模型以兩黨為主。
- [Hyndman等，時間順序驗證](https://otexts.com/fpp3/tscv.html)：訓練與測試按時間分離。
- [NumPy對稱特徵值分解](https://numpy.org/doc/stable/reference/generated/numpy.linalg.eigh.html)：對稱協方差的計算工具。
