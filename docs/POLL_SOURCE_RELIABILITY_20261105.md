## 修復

1. `scripts/formosa.py`：移除將 HTML bytes 一律強制 UTF-8 解碼的做法，改由 lxml 識別文件申明的字符集；保持問卷方法及回答比例 fail-closed 門檻。
2. `site/poll-source-v52.mjs`：分別展示 `checked_at`、`published_at` 和 `latest_fieldwork_date`，連同來源解析失敗數；任一時間戳不能替代另一種時間戳。最近資料訪期早不必然代表來源失效。
3. `tests/test_multisource.py`：追加 Big5 指定 charset 的原頁索引、調查文章測試。
4. `tests/test_taichung_primary_20261105.py`：覆蓋一方PDF來源、樣本方法、回答合計、歷史回溯截點與候選人模型名單匹配；舊版三方支持資料不應當把不投票類別混入，但候選人研究模型可另行處理該觀測。

## 尚待處理

TVBS另有不同問卷格式的PDF，仍有自動解析失敗項目。每份失敗報告必須逐一對照原始題目與表格，不能僅靠寬鬆正則表達式或猜測補值。ETtoday的RSS索引發現數仍可能是0，後續需替換更可靠的原站文章索引。資料源顯示`degraded`時，不應聲稱已覆蓋全台最新所有民調。
