# 2018—2022 中選會鄉鎮市區投票率面板與 GIS

資料屬性：歷史選舉**實際觀測數值**；研究比較，不是2026年投票率預測，更不是投票率改變對候選人的因果效應。

## 研究背景與進展

在2014、2018、2022三屆22縣市長選舉中，中央選舉委員會的公開投開票所CSV資料已有65場完整逐站對帳、48,902條可追溯紀錄，2022嘉義市對應原始資料暫只有區級資料。原始表每條有選舉人數、投票數、有效票、無效票、行政代碼及投開票所號。資料源：https://data.cec.gov.tw/選舉資料庫/votedata.zip

不能直接用同號投票所配對不同選舉：設站數和村里界會變動，台北2014區級欄位也與後續資料的命名和行政代碼不同。本階段僅以**2018、2022具有相同縣市、同一行政區代碼和正規化中文名稱的鄉鎮市區**建立面板；沒有同時滿足條件就必須排除，2014保持獨立歷史觀測資料。

## 檢驗流程

- scripts/build_turnout_district_panel.py 讀取官方來源重建的 data/cec-precincts/index.json 與各縣市逐站JSON，核對其SHA256、來源年份、縣市、所有投票所不重複、有效票＋無效票＝投票數、投票數≤選舉人數。
- 各選區先聚合為「行政區代碼 + 名稱」分組，再要求每個縣市的有效票、無效票、投票數及選舉人數總和與事先經核對的 data/candidate-history-cec.json 原值完全一致。
- 雙年份代碼與行政區名稱同時匹配時才報告實際投票率差：2022(投票數÷選舉人數)−2018(投票數÷選舉人數)，換算為百分點；不以各投開票所率的簡單平均取代全體統計。
- 明確報告跨年可配對縣市數／鄉鎮數、未配對行政區、2022選民涵蓋率、兩屆站點數、選舉人數差異、實際投票率和無效票率。
- 生成 data/turnout-district-panel-2018-2022.json，網站 ?view=turnout 於「中選會投開票所原始資料」之前展示區級歷史GIS；使用既有行政區TopoJSON依中文名稱匹配，未匹配單位灰色，不生成可疑推算結果。
- 出處與原始樣本仍可直接檢查。實際2018／2022行政區名稱與代碼一致並不證明兩屆行政區邊界或人口組成完全沒有改動；2022嘉義市獨立投票日期必須分層處理。

## 模型分層限制

本次只建立了**可審計的歷史投票參與面板**，不使用投票所聚合資料推斷個人的政黨偏好，也沒有將「提高投票率讓誰受益」納入正式HB-TLEF。下一步如要建立有經驗證據的2026投票率預測（但非個體投票操控），需明示樣本外測試日、依行政區對齊人口與選舉人數特徵、投票所級無效票區分、共同的地區隨機效應，以及可供驗證的選民參與調查。跨年行政區邊界需在地理資料上審核後才能直接以同一空間單位解讀。只從2018與2022兩個時點不應宣稱穩定因果參數或候選人投票率紅利。
