# 投票率影響與敏感度：資料及模型方法

更新：2026-10-28。本功能是歷史實際資料加條件性數學界限，並非已校準的2026投票率預測。

## 資料來源

資料取自中央選舉委員會委託研究《111年地方公職人員選舉及憲法修正案公民複決投票統計分析》，表1-4（2018縣市長）及表1-7（2022縣市長）。官方PDF：
https://web.cec.gov.tw/api/file/26069791-664e-45ff-901c-fb9d742cfd86.pdf

2018：選舉人數19,102,502；投票數12,791,449；投票率66.96%。
2022：選舉人數19,181,901；投票數11,695,610；投票率60.97%。

22縣市原始整數與來源保存在 data/turnout-history-2018-2022.json，發布時逐項核算兩年的全國加總。投票數含無效票，不等於候選人有效得票數。2022年嘉義市長選舉於12月18日單獨舉行，跨年直接比較受投票日期差異影響。2026實際選舉人數與投票率均未知。

## 情境的數學含義

令 T 為該縣市2022年總投票數／選舉人數；p_i 為正式模型一條抽樣內候選人i的有效票占比；d 為人為設定的投票率百分點變化除以100；變動後投票率 T+d 必須在0與1之間。

投票率增加時 (d ≥ 0)，新選民的投票選擇未知；候選人的有效票占比的上下界分別為 T*p_i/(T+d) 和 (T*p_i+d)/(T+d)。

投票率減少時 (d < 0)，減少的選票可能來自任何候選人；上下界分別為 max(0,T*p_i−abs(d))/(T+d) 和 min(T*p_i,T+d)/(T+d)，並截斷在0至1。

為使總投票數（含無效票）與模型的有效票占比可比，這套界限明示假定無效票率不隨投票率改變；不是從歷史數據學到的因果效應。候選人上下界各自可能實現，但不能把各人的上界同時相加當作一組預測。不把區間稱為信賴區間。

領先優勢的條件性穩健判準：若某次原始聯合抽樣的前二名占比差距 m 滿足 T*m > abs(d)，即使受影響的票全流向第二名或全部從第一名減少，該次抽樣也無法被逆轉。頁面顯示滿足條件的抽樣比例，不等同於候選人的勝選機率；不穩健只表示結果有可能改變，不表示實際一定改變。

票數增減估算以2022實際選舉人數乘以d，僅用於歷史分母下的規模展示，不聲稱是2026的預測投票人數。

## 資料與功能隔離

發布一個獨立的投票率頁面（?view=turnout），可選擇22縣市及相對2022年的-10、-5、0、+5、+10個百分點情境；顯示2018及2022實際投票率、票數規模、候選人有效票占比的數學上下界及2,000次模擬的領先差距穩健比例。

不修改 HB-TLEF 正式勝選機率、正式得票率、Polymarket 實驗權重、聯合抽樣路徑或GIS預測。不能從總體投票率推斷哪一黨或哪位候選人受益；那需要實際選民參與和投票意向的聯合數據，否則有生態推論謬誤。

要進一步建立可以進入正式模型的投票率因素，需要：2014/2018/2022正式各投開票所參與數、有效／無效票、行政邊界版本；選民調查中投票參與與候選人意向的聯合測量；固定時間點的跨選舉週期留出測試，並檢驗新參數是否真的改善已配對樣本的得票誤差、Brier與校準。使用相同民調訊息的預測市場不得在未處理相關性的情形下重複加權。
