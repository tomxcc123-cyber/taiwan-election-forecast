# 中央選舉委員會投開票所歷史資料導入與核驗（2026-10-28）

## 完成的數據層級

中選會選舉資料庫和開放資料網站提供2014、2018、2022年地方首長選舉的歷屆概況、分投開票所投票人數及得票記錄。官方來源：
- https://db.cec.gov.tw/
- https://data.cec.gov.tw/選舉資料庫/votedata.zip
- https://data.gov.tw/dataset/13119

已於GitHub Actions中下載官方原始壓縮檔（110,316,470 bytes／1,137個ZIP項目，來源檔本身不是CSV）。內有歷屆選舉的 elbase.csv（地理區代碼）、elprof.csv（有效票、無效票、投票數、選舉人數等）及 elctks.csv（候選人得票），個別年度存在CSV編碼及欄位的差異，不能只按2022欄位假設解碼2014。

核實結果：66場2014、2018、2022縣市長選舉，65場可逐站核對，共48,902個歷史投開票所記錄；有1場（2022年嘉義市）在本次可核對原始檔中為區級資料，會在索引中標註，不推造投票所資料。

## 技術流程

1. source: scripts/import_cec_open_csv.py，直接讀官方ZIP中完整的2014、2018、2022縣市長選舉CSV，僅從符合選舉類別的市長／縣市長表讀取。
2. 使用原始行政區代碼與對應名稱標記縣市、鄉鎮、村里、投開票所編號；同一年省市、縣市、選區、鄉鎮、村里、站點6欄共同組成一個站點鍵。不能拿不同年份相同的站號做一對一對照。
3. 硬性校驗：每站有效＋無效＝投票數、投票數不超選舉人數；投開票所鍵不重複；各投開票所有效票、無效票、投票數、選舉人數加總，須與既有 data/candidate-history-cec.json 2014/2018/2022整數原值完全一致。
4. 生成 data/cec-precincts/index.json（66場資料覆蓋、來源、hash、排除理由），以及各場選舉一個JSON小檔，按需加載到網站。未核實的資料不提交，也不輸出虛擬站點。
5. GitHub Pages構建時核實 index 完整性，再部署按需載入的逐縣市逐年份檔案。頁面位於 ?view=turnout 中，新增原始數據／區級匯總／投票所明細區。

中選會原始ZIP體積較大，官方抓取僅在經核實的歷史索引尚未存在時啟動；既有已核驗檔案不自動覆寫。新增資料只用於觀察及研究，不會修改 HB-TLEF 正式2026預測、Polymarket融合，也不會以投票所投票率推定個體政治態度或政黨認同。

## 新資料能做什麼，不能做什麼

能做：歷屆投票所投票率分布、行政區內差異、無效票率、跨鄉鎮市區的歷史變化，以及在充分完成村里行政區界對應後，審慎比較不同年份的區域總體趨勢。

尚不能做：直接以相同投票所編號比對2014→2018→2022，因投票所邊界可能重編；不能用聚合票數作出選民個體投票行為推論（生態謬誤）；不能在沒有個體選民資料與樣本外驗證下推斷「提高投票率會讓某政黨受益」。2026實際投票率仍未知。

## 驗收命令

- 官方CSV／歷史 XLS 格式測試：python -m unittest discover -s tests -p 'test_cec_*.py' -v
- 投開票所網站單元測試：node tests/precinct-turnout.mjs
- 原始ZIP正式入庫：python scripts/import_cec_open_csv.py --zip PATH_TO_ORIGINAL.zip --history data/candidate-history-cec.json --output data/cec-precincts
- 網頁：?view=turnout（投開票所歷史資料模塊）。

資料取自官方報告，不納入任何下單、交易、組織動員或針對政治偏好的個體分類。
