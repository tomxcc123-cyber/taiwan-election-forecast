## 一次性發布

1. 將此目錄內容放入已授權的 GitHub 倉庫，預設分支使用 `main`。
2. 在倉庫 Settings > Pages，將 Source 設為 **GitHub Actions**。
3. 啟用 Actions 工作流程 `Update polls and publish website`。首次可執行 Run workflow；其後排程自動執行。
4. 成功部署後，以 workflow 的 `github-pages` environment 回傳網址為準。

GitHub Pages 不需要在前端填 API 金鑰。排程使用倉庫內建 GITHUB_TOKEN，不使用個人長期權杖。若帳號限制工作流程寫入，需一次性開啟倉庫 Actions 的讀寫權限。Pages 可用性依倉庫可見性及帳號方案而定。

## 近期民調的自動核驗（2026-10-28）

山水民調／震傳媒及皮爾森數據／鉅聞天下的來源文章現可由待核驗佇列進入專用的**投票意向**解析與校驗步驟；只有訪問日期、樣本、候選人、回答比例、調查方法等條件通過的文章才寫入 \`data/polls.json\` 的 \`records\`，再由 \`model/polling.py\` 的候選人名單與重複訪問校驗決定是否入模。看好度、票流、施政滿意度及頁面格式異常一律不自動入模，保留待核驗原因。

部分文章只披露候選人支持率，並未完整拆分未表態、其他候選人或不投票。此時存成 \`response_mass_unreported\`（未分類回答比重），**不把剩餘比例冒充未表態**；僅以已披露候選人的相對支持作測量，額外加入比例缺漏及網路調查方法的保守誤差。這是尚未完成校準的研究假設，不代表新資料必然提高準確率；舊版三方模型不納入此類不完整回答分類。實際上線資料仍以部署後的 \`poll_audit\`、驗證頁和 GitHub Actions 紀錄為準。

## 市場觀察與民調覆蓋（2026-10-28）

新增只讀 [市場觀察研究頁](docs/MARKET_OBSERVATORY_RELEASE.md)；以官方 Gamma 公開資料的排程快照提供台灣縣市長合約價格、流動性、有限歷史走勢，以及與現行候選人模型的非因果數值對照。「預測總覽」新增民調證據覆蓋 GIS 圖層，「民調中心」新增22縣市表。市場資料與正式模型完全隔離，不提供下注或交易功能，無資料不補值；選前發布暫停同樣涵蓋市場資料。

### 市場訊號的實驗性入模

市場觀察頁新增勝選機率 **融合試驗版本**（0%、5%、10% 市場權重）及來源品質門檻，詳細算法參見 [市場觀察與融合研究說明](docs/MARKET_OBSERVATORY_RELEASE.md)。融合結果確實根據市場價格改變候選人勝選事件概率，但屬尚未校準的旁路預測，不修改正式 HB-TLEF 得票率、聯合抽樣、全國席次或基準勝率。缺乏足夠歷史選舉市場結算資料，正式模型不採用固定市場權重。

### 市場融合的回測證據留存

現已新增每個台北日曆日的模型／市場配對凍結紀錄，包含22縣市的來源時間、對應候選人、基準概率與5%／10%融合結果，以及不適用原因；發佈網頁可檢視。選後的中選會官方結果評分程式只接受明確提供的正式結果，按固定選前時間窗口計算多類別 Brier 與 log loss；目前沒有任何已經結算的2026結果，也不能宣稱融合準確率提升。詳見 [市場觀察與配對回測方法](docs/MARKET_OBSERVATORY_RELEASE.md)。

### 22縣市投票率敏感度研究（2026-10-28）

新增獨立「投票率」頁面，以中選會委託研究2018／2022年全台22縣市長選舉的選舉人數及投票數，顯示±5／±10百分點參與情境、以2022選舉人數為分母的條件票數差額、候選人有效票占比數學上下界，以及原始聯合模擬中領先差距在任意邊際選民分配下仍無法逆轉的比例。**不估計2026實際投票率、不推斷新增選民支持任何候選人、不修改正式HB-TLEF模型或Polymarket實驗權重。** 詳見 [投票率研究來源與方法](docs/TURNOUT_SENSITIVITY_RELEASE.md)。

### 中選會投開票所資料（2026-10-28）

已核實中選會官方 `votedata.zip` 下載與格式；加入按2014、2018、2022地方首長選舉提取、逐投開票所守恆及縣市總計對帳的正式導入流程。66場地方首長選舉中，65場取得逐站資料，共48,902條投開票所記錄，1場只具區級合計，皆明確標示。**相同投票所編號跨年不可直接視為同一地點**；不由聚合數據推論個體選票，不改寫正式2026模型。詳見 [中選會投開票所導入與審計](docs/CEC_PRECINCT_RELEASE.md)。

### 2018—2022 鄉鎮市區投票率比較與 GIS

在中選會已對帳之48,902筆原始投開票所記錄之上，新增2018→2022分縣市、鄉鎮市區投票率面板，僅比較行政區代碼與名稱皆一致的單位；GIS 按歷史投票率百分點變動着色，標註排除與涵蓋率，並保留原始票數。**不是2026年投票率預測，也不是候選人得票因果效應。** 詳見 [縣市長選舉投票率GIS研究說明](docs/CEC_TURNOUT_DISTRICT_PANEL.md)。

### 2018—2022 候選人得票、投票率與時間順序留出研究

已通過中選會2018／2022每個投開票所候選人票數＝有效票、原始縣市候選人總票數之雙重核驗；366個匹配行政區中338個（18縣市）可描述兩黨投票結構的跨年差異。2022年嚴格留出投票率回測：沿用2018值MAE為6.2273pp，套2014→2018舊趨勢修正MAE為6.9655pp。選後生態關聯經縣市去平均加權後約−0.04879；**這不是因果效果或可直接作2026年候選人概率的修正**，正式模型不變。詳見 [中選會候選人得票與投票率回測研究](docs/CEC_TURNOUT_ASSOCIATION_EVALUATION.md)。

### 投票率影子模型與2022固定公式回測（2026-10-28）

使用中選會已對帳的行政區歷史投票率，新增2018年以前資料限定的7組預測公式（歷史直接延用、縣市均值收縮與2014→2018舊趨勢部分延續），對2022年同一366個行政區按選民數加權計算MAE／RMSE，並以21縣市整群重抽樣觀察差異區間。**這是已看過2022回測後的探索性影子模型比較，不是額外獨立樣本外證據**；所有2026正式候選人勝率與市場融合維持不變。詳見 [投票率影子模型及資料洩漏控制](docs/TURNOUT_SHADOW_ABLATION_2022.md)。

### 2014—2018年鄉鎮市區資料已恢復，完成雙周期回測

直接從中選會2014原始 `elbase.csv` 恢復選區代碼與行政區代碼不一致時的當屆官方名稱，在不跨年拼接投票所編號的前提下，核對得到2014→2018年 **22縣市／366行政區**，並與2018→2022年 **21縣市／366行政區**做分開的時間順序驗證。上一屆行政區率向縣市率收縮25%，兩屆加權MAE分別為 **3.4343pp（原3.4979）** 和 **6.1982pp（原6.2273）**。改善很小，且非候選人勝選率之增益證據，2026正式HB-TLEF維持原版。詳見 [2014行政區資料核驗與兩周期驗證](docs/CEC_PRIOR_CYCLE_TURNOUT_VALIDATION.md)。

## 自動更新

- 每六小時執行一次；GitHub 排程可能延遲，不是即時服務或 SLA。
- 第一個已實作來源是 **TVBS 官方民調中心首頁中的 2026 縣市長報告**，最多 30 份。尚未宣称覆蓋所有機構或完整歷史分頁。
- 從官方索引找 PDF，再從原始問卷表擷取全體支持度。排除施政滿意度、政黨認同、交叉表及初選題目。
- 記錄調查開始及結束日、樣本、抽樣方式、誤差、母體文字、經費、原始來源。來源沒有披露的欄位保留缺值，不杜撰主持人或母體人數。
- 多組對陣分開存檔，不混算。新模型以登記名單中的姓名精確配對，另行檢查日期、來源、樣本、合計及重複訪問，不沿用舊三方模型的可用旗標。
- 同機構、同縣市的訪問期間重疊或報告重複時保留最新題目。不同期題目保留並以共享機構與時間協方差聯合更新。不完整對決僅提供列名人選的相對支持，額外增加選項誤差；不把未列人選當作零支持。
- 更新失敗保留舊資料。網站明示降級、來源檢查過期、最新调查過舊，不把今日抓取當成今日調查。格式大幅變更可能仍需維護程式，但日常抓取與匯入無須人工。
- 每位使用者的頁面每十分鐘讀取一次已發布的資料。瀏覽器不直接爬原始站點，避免 CORS 與前端洩漏權杖。
- 主站使用歷史候選人ridge基本面、動態高斯近似民調更新，以及2,000次候選人級聯合抽樣。每次抽樣先判定各縣市勝方，再彙總22席；無黨籍及小黨候選人不合併成虛構參選人。
- 驗證頁同時比較基本面與同一聯合引擎在無民調、零外推條件下的2022整屆留出結果。只有一個測試週期；這不代表動態民調似然或2026勝率已經校準。超參數仍是公開研究假設，不是已估計的真實效應。

## 發布限制

選舉民調公開有時間及揭露要求，參見[公職人員選舉罷免法第 53 條](https://law.cec.gov.tw/LawContent.aspx?id=GL000292)及[中選會投票日公告](https://www.cec.gov.tw/central/article/61722)。這不是法律意見；上線營運者仍須確認適用規定與素材授權。

預設採保守期間 2026-11-17 00:00 至 2026-11-29 00:00（台北時間）暫停發布整個預測站。建置器在此期間不輸出民調 JSON、模型 HTML 或地圖資產，瀏覽器另有暫停顯示保護。

**靜態站限制：排程失敗、CDN 舊快取、已下载檔案或公開 Git 歷史無法靠前端可靠撤回。這些保護不是法規遵循保證。若需嚴格定時封鎖所有端點，應使用可在伺服器/邊緣強制封鎖的託管，並以私有資料倉庫保存來源，在期限前驗證切換。** 來源未揭露主持人/母體人數等欄位時，頁面標為未列；實際發布責任仍需確認。

```sh
python -m pip install -r requirements.txt
python -m unittest discover -s tests -v
python scripts/update_polls.py
python scripts/build.py
node tests/model.mjs
node tests/candidate-engine.mjs

node tests/candidate-browser.cjs
```

`dist/index.html` 是預览，不是公開網址。部署內容只包含 `dist`，不含 `.cache` 原始報告、測試資料、工作文件或憑證。

## 結構

- `site/index.html`、`styles.css`、`candidate-app.mjs`：主站頁面與導覽。
- `model/product.py`、`joint.py`、`polling.py`：獨立候選人級模型、聯合推論及民調配對；`dist/candidate-model.json`為同版模型輸出。
- `scripts/import_cec_history.py`：唯讀解析中選會XLS、逐投票所及鄉鎮區校驗；`data/candidate-history-cec.json`為新版完整票數，不覆寫舊版歷史。
- `dist/candidate-validation.json`：與新版模型配對的66場資料審計及22場留出測試；`candidate-research.json`只供舊版研究頁使用。
- `data/survey-source-audit.json`：TEDS選後調查用途審計，不包含受訪者資料，也不作同屆選前民調輸入。
- `site/candidate-engine.mjs`：聯合抽樣上的票流、條件篩選與席次統計；`charts.mjs`：真實縣市地圖。
- `site/app.mjs`、`forecast.mjs`：保留的三方研究頁與舊模型，不再作為主站預測。
- `scripts/research_model.py`：歷史資料提取、時間切分回測與基準追溯。
- `site/base.html`：保留的原網站，建置為 `legacy.html`；公開版保護由 `scripts/build.py` 注入。
- `site/public-polls.*`：自動更新狀態、資料來源與民調清單。
- `scripts/update_polls.py`：受限來源抓取、解析、驗證、去重、原子寫入。
- `config.json`：基線日期、候選人對陣及暫停發布時間。
- `data/polls.json`：最近一次有效資料與檢查狀態，不含完整報告全文。
- `.github/workflows/publish.yml`：定時抓取、測試、保存資料、發布。

來源與元件出處見 `THIRD_PARTY.md`。原版地圖和候選人百科的外部請求仍受來源可用性限制。
